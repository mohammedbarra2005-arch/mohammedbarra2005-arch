## 🚀 Featured Project

### 🛡️ SENTINEL: Fraud Detection for ISO 20022 Payments
End-to-end platform detecting fraud in `pacs.008` / `pacs.002` transactions.

- **Transaction-level scoring:** XGBoost + SHAP explainability
- **Organized fraud detection:** Graph Attention Network (PyTorch Geometric) on a 400-account graph. It identified all 8 injected circular-transfer rings and all 5 fan-in schemes
- **Graph storage:** Neo4j with automatic NetworkX fallback
- **Backend:** FastAPI, 15 endpoints, JWT auth, isolated ML service layers
- **Frontend:** 12-page React / TypeScript investigation app (dashboard, alerts, graph explorer, explainability), tested end-to-end with Playwright
- **LLM assistant:** function-calling (Groq) answering analyst questions from real platform data
- **Transparent limits:** synthetic data, proxy fraud label, GAT compared against a logistic regression baseline

`Python` `XGBoost` `PyTorch Geometric` `SHAP` `Neo4j` `FastAPI` `React` `TypeScript` `Tailwind` `Playwright`
